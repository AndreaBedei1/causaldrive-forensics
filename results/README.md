# Results

- `robustness_campaign_manifest.json`: the manifest of the robustness campaign (frozen reconstruction, hashes,
  canonical raw-data hashes, profiles, the 35-condition matrix, seed schedule, software versions), written by
  `scripts/campaign_manifest.py` and checked by `scripts/campaign_controller.py` before any job runs.
- `robustness/frozen_campaign/`: the campaign on the 22 canonical runs: every job (`jobs.jsonl.gz`), the driver's
  summary (`summary.json|csv|md`, `figures/`) and the report (`report/`: tables, csv, json, figures), all
  regenerated by `python scripts/campaign_report.py robustness`.
- `robustness/frozen_campaign_smoke/`: the smoke test run before the campaign (same code and protocol).

The 22 canonical runs keep their reconstruction and evaluation next to the raw data in
`traces/<scenario>/<run>/reconstruction/`.  Report: `docs/ROBUSTNESS_CAMPAIGN.md`; protocol:
`docs/FROZEN_CAMPAIGN.md`.
