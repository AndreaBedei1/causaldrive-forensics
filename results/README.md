## Tables (`tables/<name>.csv|md|tex`)

- `T1_canonical_runs`: Canonical runs: recorders, road users that recorded nothing, and what the reconstruction recovered (privileged evaluation).
- `T2_sweeps`: Scenario sweeps (parameters sampled by a Halton sequence; N chosen in docs/experiment_size.md): outcomes and reconstruction accuracy per sweep (privileged evaluation).
- `T3_fusion`: Road users that recorded nothing, canonical runs: centre error of the fused states against ground truth (instants where every source track was on the entity's own road user).
- `T8_fusion_sweeps`: Road users that recorded nothing in the sweeps: fused against single-track centre error, paired per run (privileged evaluation).
- `T4_event_oracle_canonical`: Core perception events before each recorder's first contact against the ground-truth event oracle (17 runs, canonical).
- `T4_event_oracle_sweeps`: Core perception events before each recorder's first contact against the ground-truth event oracle (240 runs, sweeps).
- `T5_robustness`: Robustness of the reconstruction on the canonical runs (docs/robustness_profiles.md): mean +- SD over seeds of the metrics pooled over the runs. Baseline/impulse refreshed in final hardening; other families retain the historical implementation and its baseline (see family_provenance in summary.json).
- `T6_sensitivity_canonical`: Historical one-at-a-time sensitivity of the core events to their thresholds before the first contact (17 runs, canonical).
- `T6_sensitivity_sweeps`: Historical one-at-a-time sensitivity of the core events to their thresholds before the first contact (240 runs, sweeps).
- `T7_impulse`: Historical collision-report impulses: probability that the two reports of a matched contact pass the legacy fixed relative gate under independent report errors (Monte Carlo).

## Figures (`figures/<name>.svg|pdf`)

- `F1_event_timeline_s17`: Per-vehicle event graph of S17 on t_global: what each recorder's own sensors established about each road user (U1: the road user that recorded nothing), its own actions, and where ground truth puts the start of each CRITICAL_TTC (privileged overlay).
- `F2_alignment_errors`: Largest event-time error on t_global per run (privileged evaluation); dotted: one radar period (0.05 s).
- `F3_fusion_centre_error`: Centre error of the road users that recorded nothing, per sweep run: fused estimate against the single-track nominal box at the same instants (privileged evaluation).
